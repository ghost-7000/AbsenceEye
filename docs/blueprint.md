# **App Name**: AbsenceEye

## Core Features:

- Login Authentication: Secure login for admins and teachers using email and password credentials.
- Teacher Class Management: Teachers can create, name, and manage their classes, including adding, editing, and removing students.
- Attendance Recording: Teachers can mark students as present or absent for each class.
- Attendance Summarization: The LLM tool summarizes daily attendance across the school to assist school admin in making resource allocation decisions.
- Role-Based Dashboards: Separate dashboards for admins and teachers with relevant information and functionalities.
- Student Search and Filtering: Ability to search for students and filter by class or date.
- Dark/Light Mode Toggle: Users can switch between dark and light modes for better usability.

## Style Guidelines:

- Primary color: HSL 210, 64%, 57% (approximately #4FA0F0) to evoke trust and a professional atmosphere.
- Background color: HSL 210, 20%, 95% (approximately #F0F4F7) to offer a clean and calm canvas that makes content stand out.
- Accent color: HSL 180, 50%, 40% (approximately #33A6A6) to subtly highlight interactive elements and important calls to action, drawing the user's eye without overwhelming the interface.
- Headline font: 'Space Grotesk', sans-serif, for a modern, digital-friendly aesthetic.
- Body font: 'Inter', sans-serif, for readability and clarity, which supports the app’s core functional design.
- Responsive design to ensure seamless usage across devices (Mobile, Tablet, Desktop).
- Clean and minimalist icons for easy navigation and understanding.
